🔗 Generic Rule Indexing Flow (Naga Limited Travel Policy)

1. User Input: Fill form field and blur (leave field)
2. Frontend: Plugin sends field_name + field_value to backend API
3. Backend (Rule Index): Dynamic indexer extracts rules from policy based on entity types
4. Backend (Matching): Matches rule names, conditions, and field references against context
5. Backend (Evaluation): Evaluates conditional rules (IF statements) and constraints
6. Backend (Decision): Returns valid/error based on rule conditions and numeric comparisons
7. Frontend (Display): Show popup with status, message, and matched rule details
8. Performance: ~100-200ms per validation using dynamic pattern generation
