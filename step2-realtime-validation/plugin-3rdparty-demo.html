🌐 Policy Plugin for 3rd Party UIs

Drop this single script tag anywhere and it works - auto-detects forms and validates fields

Installation (Copy & Paste)

<script src="http://localhost:8888/modules/policy-plugin.js"></script>

That's it! Add this ONE line to any website and policy validation starts working automatically.
✓ How it works:
1. Plugin auto-detects all forms on the page
2. Attaches blur listeners to input fields
3. When user leaves a field (blur event), field value is validated
4. Popup appears with relevant policy rules and suggestions
5. Works on ANY 3rd party website - no configuration needed

🚀 How to Use on Your 3rd Party Websites

Option 1: Add to HTML (Browser Extension) 
<!DOCTYPE html>
<html>
<head>
  <!-- Your existing HTML -->
  <!-- ADD THIS ONE LINE: -->
  <script src="http://localhost:8888/modules/policy-plugin.js"></script>
</head>
...
Option 2: Inject via Browser Console 
const script = document.createElement('script');
script.src = 'http://localhost:8888/modules/policy-plugin.js';
document.head.appendChild(script);
Option 3: Browser Extension (Recommended for Production)

Wrap policy-plugin.js in a Chrome/Firefox extension manifest that injects the script into all pages.
